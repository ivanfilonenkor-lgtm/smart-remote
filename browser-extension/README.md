# Smart Remote — Video Sites

Локальное расширение для Chrome/Edge, которое связывает поддерживаемые видеосайты с
`remote-core.exe` через `ws://127.0.0.1:8765/v1/browser`.

Поддерживаются:

- AnimeVost — серии, play/pause, безопасно распознанный пропуск опенинга и автопереход;
- YummyAnime (`old.yummyani.me`) — серии и синхронизация штатного автоперехода сайта.

Расширение не получает доступ ко всем сайтам: в `manifest.json` перечислены только явно
поддерживаемые домены. Общая логика видео находится в `content.js`, а особенности сайтов — в
небольших файлах `adapters/`. Поэтому новый сайт добавляется без изменений Android и RemoteCore.

## Установка

1. Запустите `remote-core.exe`.
2. Откройте `chrome://extensions` (Chrome) или `edge://extensions` (Edge).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
5. Откройте страницу просмотра на одном из поддерживаемых сайтов.

После обновления файлов нажмите кнопку «Обновить» на карточке расширения. Если Chrome запросит
новое разрешение для YummyAnime, подтвердите его — без этого адаптер сайта не запустится.

Переключатель «Автопросмотр» хранится в расширении на ПК. На AnimeVost расширение нажимает только
явно распознанную кнопку опенинга/вступления, а после конца серии запускает пятисекундный переход.
На YummyAnime переключатель синхронизируется со штатной настройкой сайта `autoSkipNextEp`, чтобы
два независимых механизма не переключили две серии подряд.

Инструкция для добавления новых сайтов: [adapters/README.md](adapters/README.md).
